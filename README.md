# Metis Landing Page

A modern, interactive landing page built with React, Vite, and Tailwind CSS. Features smooth animations, responsive design, and engaging user experiences.

## 🎨 Features

- **Modern UI/UX** - Responsive design with Tailwind CSS
- **Smooth Animations** - Framer Motion and GSAP for fluid interactions
- **Performance Optimized** - Built with Vite for fast development and production builds
- **Accessible** - Custom cursor and interactive components
- **Brand Focused** - Showcases brand story, products, case studies, and testimonials

## 📦 Tech Stack

- **React** 19.2.6 - UI library
- **Vite** 8.0.12 - Build tool and dev server
- **Tailwind CSS** 3.4.19 - Utility-first CSS framework
- **Framer Motion** 12.40.0 - Animation library
- **GSAP** 3.15.0 - Advanced animation library
- **Lucide React** 1.17.0 - Icon library
- **Lenis** 1.3.23 - Smooth scrolling
- **Cheerio** 1.2.0 - HTML parsing
- **ESLint** - Code linting

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install
```

### Development

```bash
# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
# Build for production
npm run build
```

### Preview

```bash
# Preview the production build locally
npm run preview
```

### Linting

```bash
# Run ESLint
npm run lint
```
